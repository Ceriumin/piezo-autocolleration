# Autocorrelation function to determine fundamental pitch from a piezoelectric sensor

Piezoelectricity is an electric charge that accumulates in certain solid materials, in this case ceramic as part of a piezoelectric disk where 
its deformation produces a charge. If we are to apply these principles here, it means that it can theoretically 'deform' to the shape of sound waves and frequencies. This is
usually how a speaker works. Buzzers in toys are just these ceramic disks but they have a charge applied to them to resonate and produce a sound. This also suggests that we can
use them the other way round and extract sound waves from them, which is an oversimplified version of how a microphone also works.
